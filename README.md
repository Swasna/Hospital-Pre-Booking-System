# Hospital Pre-Booking System

## Project Description

The Hospital Pre-Booking System is a Python-based mini project developed using Visual Studio Code. It allows users to add, view, search, and cancel patient bookings efficiently. The system uses file handling to store booking details, making it simple, user-friendly, and suitable for beginners.

## Features

* Add patient bookings
* View all bookings
* Search patient bookings
* Cancel bookings
* Store booking details using file handling

## Technologies Used

* Python
* Visual Studio Code
* File Handling

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run `python main.py`.
